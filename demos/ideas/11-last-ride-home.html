About this demo

The idea
A late-night board for Adams Morgan bar-goers, restaurant staff and visitors that answers one question: can I still make the train, and if not, which bus or bike? Bars that opt in put a QR code on the table.
What's real here
Every bike, e-bike and open-dock count comes from Capital Bikeshare's public GBFS feed, pulled 2026-10-31 (snapshot 2026-10-31 16:49 UTC). Station locations come from DC GIS's Metro Stations layer, so the walk times are real estimates: Woodley Park is 0.94 km and Columbia Heights 1.08 km from 18th & Columbia as the crow flies.
What's mocked
The train countdowns and bus arrivals are sample values. We have no WMATA API key, and Metro's late-night closing times change, so this page states no real closing times; it links to each station's first-and-last-train page instead. Bus route names are placeholders because the 2025 Better Bus redesign renamed routes. The share link and the sponsor are mockups.
To build it for real
Register a free WMATA developer key. A Cloudflare Worker on a 30-60 second cron calls Rail Predictions for the two stations and bus GTFS-RT trip updates, merges GTFS static for last-trip times, and caches one JSON blob in KV that every visitor reads (WMATA's terms forbid one key per user and re-exposing the data as an API). GBFS is polled the same way. Refresh bus GTFS weekly with a GitHub Action so route renames flow through. Then print table tents for two or three bars.
