Know a building that looks empty?

DOB inspects buildings reported as possibly vacant. You can report one through DC 311. Owners can apply for exemptions (for example, during active construction) through DOB, which is why some listed buildings are taxed at regular rates.

About this demo

The idea
A neutral, data-only tracker of buildings DC classifies as vacant or blighted in each neighborhood, with tax class and any permit activity. Daily snapshots turn the list into a record of how long each building has been listed and which ones came back into use.
What's real here
Everything shown. This run pulled 64 points from DOB's Vacant and Blighted Building Addresses inside the DC Health Petworth boundary, joined 64 of them by SSL to OTR's Vacant and Blighted tax extract for class, property type and assessment, and matched building permits issued in the last 24 months by SSL. Owner names are in the tax extract and were never requested.
What's mocked
Nothing is invented. Not built yet: "listed since" dates and the "back in use" list, which need the daily snapshots the product would start collecting; DC does not publish a listing date.
To build it for real
Snapshot the list nightly to record first-seen and removal dates; add the Adams Morgan page; show a small "recently removed" section; offer an RSS feed for ANC offices; keep wording neutral and never add owner data.
