What the sheets can and can't tell us

  • Census day was April 1, 1950. Each Form P1 page has a line for each of 30 people, and six people per page were asked extra "sample" questions. NARA
  • Renters versus owners is not available: the housing schedule was on the back of the form, was never microfilmed, and the paper originals no longer exist. NARA
  • The records opened on April 1, 2022, after the 72-year privacy restriction. NARA
  • NARA's own name index was built with AI/OCR and isn't 100 percent accurate. NARA

See the original sheets at the National Archives →

Names stay on NARA's site. This project never transcribes, indexes or displays them. Some people counted in 1950 are still alive.

How the real version gets built

  1. Find the district. Match each block to its 1950 enumeration district using NARA's ED maps and descriptions (Steve Morse's 1950 ED tools help).
  2. Download the sheets. NARA publishes every population schedule, ED map and description as open data on AWS, free and with no account. AWS Open Data
  3. Transcribe only the non-name columns: relationship, age, birthplace, occupation. Run OCR or Claude vision on roughly 200–400 sheets per neighborhood, then spot-check by hand.
  4. Aggregate and suppress. Roll up to block or ED, fold small groups into "other", and publish counts and charts only.
  5. Link out for names. Each portrait links to the matching sheets on NARA's viewer.

About this demo

The idea
A per-block statistical portrait built from the 1950 census manuscript schedules, released free in 2022: what people did, where they came from and how they lived. A social-history page for every block, not a people search.
What's real here
The facts about the 1950 census and its records (census day, the Form P1 layout, the missing housing schedule, the 2022 release, NARA's AI/OCR name index, the AWS open-data copy), each linked to NARA or AWS. The block and neighborhood are real places.
What's mocked
Every count and chart. They are invented sample figures that show the layout, because no per-block 1950 statistics exist to query. The enumeration district number is a placeholder.
To build it for real
For each neighborhood, map blocks to 1950 enumeration districts, pull those sheets from NARA's AWS bucket, transcribe only the non-name columns with OCR or Claude vision, spot-check, aggregate with small-group suppression, and add today's ACS figures for comparison. Expect 40–80 hours for the first neighborhood.
