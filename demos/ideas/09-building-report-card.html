About this demo

The idea
One page per large apartment building that puts its 311 history, permits and surroundings in one place for renters comparing buildings. Revenue comes from renters-insurance and moving affiliate links. Records are shown raw, with no grade, because a grade is an opinion that invites defamation claims.
What's real here
All records. This run matched 99 311 requests logged at 3800 NEW HAMPSHIRE AVENUE NW in the 2019–2026 yearly layers, 7 building permits at the address in the 2016–2026 layers, server-side crime counts in a 300 m box, the unit count from DC's Address Points and property type from OTR's tax extract. Owner names, applicant names and 311 free-text details were never requested.
What's mocked
The affiliate card is a placeholder. The building was chosen as a large elevator building inside the Petworth boundary, with no judgment about it. Walk time is a straight-line estimate, not a routed walk.
To build it for real
Generate one page per building with 20+ units from Address Points; add DOB housing-code inspection and violation records where published; show a neighborhood baseline (requests per unit) so numbers have context; offer a landlord response box; keep any paid "verified building" profiles off the .org sites.
Independent project; not affiliated with DC Government, any ANC, BID or property owner. Sources: Address Points, Integrated Tax System Public Extract, 311 City Service Requests, Building Permits, Crime Incidents and Metro Stations via Open Data DC. Generated 2026-10-31 17:02 UTC.
