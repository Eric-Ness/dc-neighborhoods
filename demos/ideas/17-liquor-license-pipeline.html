About this demo

The idea
A tracker of every alcohol licensee in the neighborhood: who holds a license, what kind, which ones were cancelled, and (in the full build) which new applications are open for protest. Written for nightlife fans and nervous neighbors alike.
What's real here
The licensee list, classes, endorsements, capacities and map come from ABCA's "Alcohol License Business Locations" layer, and the cancelled list from ABCA's "Alcohol License Cancellations" layer, both queried live inside the Adams Morgan boundary on 2026-10-31. License holder (applicant) names are never requested; only the public trade names are shown.
What's mocked
The "New applications & protest deadlines" box is sample data with placeholder names. The moratorium-zone overlay is left off because the layer's Adams Morgan polygon was last edited Dec 13, 2023. Cancellation dates aren't in ABCA's file, so the cancelled list can't be sorted by recency.
To build it for real
Parse ABCA placard notices (PDF) weekly for new applications and protest deadlines; diff the licensee layer night to night to catch new and dropped licenses with real dates; add ANC 1C liquor-committee agendas; draw the moratorium zone once ABCA's layer matches the current rule.
