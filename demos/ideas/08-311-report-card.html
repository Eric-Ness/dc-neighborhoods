Reading these numbers

This is reported closure: the date an agency marked the request closed in 311. A closed request is not always a fixed problem, and some types (bulk pickup, yard waste) close on a schedule rather than on demand. Use the numbers to ask questions, not to grade crews.

About this demo

The idea
A live scoreboard of 311 requests per neighborhood: what people report, how long each type takes to close, and how that compares with the rest of DC.
What's real here
Everything on this page was pulled from Open Data DC's 311 City Service Requests layer on 2026-10-31. Medians are computed server-side by DC's ArcGIS server (50th percentile of RESOLUTIONDATE − ADDDATE, status 'Closed' only, duplicates and transfers excluded) over every closed request in the window, not a sample. Citywide uses the same query with no boundary. Neighborhood boundaries are DC Health planning areas. The 'still open' list fetches only type, address and date, and coarsens addresses to the hundred block before use.
What's mocked
Nothing in the numbers. The layout, the auto-written paragraph's wording and the 'faster/slower' threshold (10%) are design choices for the demo. Free-text details and exact addresses are never requested.
To build it for real
Add the query to the nightly ingest (one grouped stats call per neighborhood plus one citywide), store monthly snapshots so trends survive the January layer rollover, add a per-block map of open requests, and publish a printable one-pager for ANC meetings.
